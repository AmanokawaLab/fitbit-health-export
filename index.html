fitbit-health-export

fitbit-health-export は、Google Health API を使用して、 ユーザー自身の健康・フィットネスデータを取得し、 個人利用のためにエクスポートするツールです。

目的

このアプリケーションは、ユーザー本人がGoogle Healthに保存されている 健康・フィットネスデータを取得し、 個人的なバックアップや分析に利用できるようにすることを目的としています。

Google Health API の利用

このアプリケーションは、ユーザーが明示的に許可した範囲の Google Healthデータにのみアクセスします。

取得したデータを広告目的で利用したり、 販売したり、第三者に提供したりすることはありません。

Google Health APIから取得した情報の利用は、 Google Health API Developer and User Data Policy の Limited Use requirements に従います。
